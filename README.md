# ミウラパズル（仮称）

4×4 のラテン方陣の伏字パズル。問題番号を入れると同じ問題が出るので、友達とタイムを競える。

- 依頼：三浦さん（ドクターQ）
- 作り：HTML 1枚（`index.html`）。外部のファイルやライブラリは読み込まない
- 公開：GitHub Pages（main ブランチの直下をそのまま配信）
- 「記録をコピー」の機能は https のページでしか動かない（GitHub Pages は https）
- 画面：スマホの1画面に収まる作り（縦にスクロールしない。高さは `100dvh` 基準、盤面は幅と残りの高さの小さいほうに合わせた正方形）。パソコンとタブレットでは、スマホの幅のカードを真ん中に出す
- 問題の切り替え（問題番号の呼び出し・ランダム・前／次の問題）は、右上の「⋯」のメニュー（下から出る画面）にある
- 記録（完成時間・問題番号・感想・コピー・次の問題へ）は、クリアしたときに出る結果の窓にある
